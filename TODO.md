- [ ] Model selection without the test set, plus uncertainty on every comparison.
  - **Problem.** The headline figure and the README table report the "best classifier" per embedder, chosen as the most accurate of six classifiers *on the test split*. This is selection on the test set, so the best-of-six numbers are optimistically biased. Each run is also one train/test split with no error bars. That makes small gaps impossible to read: 99.5% vs. 98.8% on SMS Spam is 7 of 1,035 texts, and 74.6% vs. 74.7% on Emotion is 4 of 4,000. A reviewer or interviewer will ask about both.
  - **Selection.** Choose the classifier (and any hyperparameters) on the training data only. Either hold out a validation split from `train.parquet` (e.g. 15%, stratified, fixed seed) or use stratified k-fold cross-validation on train (k=5). Then refit the chosen classifier on all of train and score it once on test. Record which classifier was chosen and its validation score in the results JSON, so `results/plot_summary.py` can read the choice instead of taking `idxmax` over test accuracy. Optionally tune a small grid per classifier at the same time (`C` for the SVMs and logistic regression, `gamma` for the RBF SVM, depth and estimators for XGBoost), since everything currently runs on defaults.
  - **Confidence intervals.** For each reported accuracy and macro-F1, compute a 95% bootstrap interval over the test texts (resample test indices with replacement, e.g. 1,000-10,000 times, take the 2.5th and 97.5th percentiles). That needs per-text predictions, so have `experiment.py` save them, e.g. `results/<dataset>_<embedder>_predictions.csv` with `text`, `label` and one column per classifier. Show the intervals as error bars in the figure and as ± in the table.
  - **Paired comparison with Claude.** Claude's per-text predictions are already in `results/claude/*_predictions.csv`, on the same test texts. Once the classifiers' predictions are saved too, run McNemar's test (or a paired bootstrap of the accuracy difference) between the chosen classifier and Claude on each dataset. Report the p-value or the interval of the difference. This is the honest way to back "+14 points on Emotion" and "tie on SMS Spam".
  - **Repeats.** If time allows, repeat over a few seeds or splits (e.g. 5) and report mean ± std. This matters most for SMS Spam, where the test set is small and near-saturated.
  - **Done when.** The figure and table use the chosen classifier with error bars, the README states the selection protocol, and the "picked on the test split" and "no confidence intervals" caveats come out of the README's Limitations paragraph.
